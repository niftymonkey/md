Notes on the patch endpoint

Three things stood out when I went back through the PATCH design after the review on #20. The middleware didn't change shape, but the contract for partial updates needed a fence around what counts as a no-op response, and the title-derivation rule needed to survive a content-only update without surprising the operator.

The bigger lesson is one I keep relearning. When the spec is "update only what changed," the trap is letting the API silently accept noise: empty strings, whitespace-only payloads, fields that match what was already stored.

The auth gate

Bearer-first, session fallback. The order matters when an authenticated browser tab is also sending an API key for some reason. We chose bearer first because the API client is the more deliberate caller.

Bearer flow

Bearer is checked synchronously against MD_API_KEY. Owner-id is stamped from MD_API_OWNER_ID.

Session fallback

Session is checked against the WorkOS allow-list. Owner-id is the user's WorkOS id.

// max upload size — 1 MB, both bearer and session paths share the same cap
const MAX_BYTES = 1024 * 1024;

export async function resolveOwner(req: Request): Promise<Owner | null> {
  const bearer = req.headers.get("authorization")?.trim();
  if (bearer === `Bearer ${env.MD_API_KEY}`) {
    return { id: env.MD_API_OWNER_ID, source: "bearer" };
  }
  return null;
}

Edge cases

Whitespace-only updates count as no-ops. Empty strings reset the title to derived. Concurrent writes are last-write-wins for v1.

Migration plan

Ship the no-op detection in a follow-up; existing clients won't notice because they send full payloads. The 422 path waits until we have a real schema validator wired in.

Lives behind the watermark tooltip → "settings" or ⌘,. Sectioned, list-shaped, no card chrome. The "auto-show outline" toggle here is the master kill-switch.

Settings

Operator preferences and API token management for md.

Reading

Auto-show outline
When enabled, the outline panel auto-opens on docs with three or more H2 headings. You can hide it per-doc via the watermark menu. When disabled, the outline only opens when you toggle it.
Default width
Article column width for new doc views. Reading is comfortable for prose; full uses the wider container for tables and wide diagrams.

API tokens

Personal access tokens replace the static MD_API_KEY. Each token is scoped and revocable. The token value is shown only at creation.

Defaults

Default kind
Pre-fills the kind field on new uploads. Leave blank for none. Free-form (note, rep, synthesis, anything).
Allow search engines (default)
When on, new docs default to indexable. Per-doc toggle in the edit form overrides this. v1 default: off (every doc is noindex,nofollow).
