reader · responsive behavior

Reader toolbar — width-driven orientation

One toolbar, two orientations, picked by the surface's own width. At wide viewports the cluster sits horizontally in the top-right, its top edge aligned with the article H1. When the surface narrows past ~720px and the horizontal cluster would collide with the H1, the cluster flips to a vertical column on the right edge — width pill compresses to single-letter R / W, icon buttons stack, prose gains the right-padding it needs to wrap before the column. The top of the column still aligns with the H1's top edge.

Resize your browser window to see it switch. The container query fires on the frame's own inline-size, so the same component swaps shape regardless of which surface it's mounted in.
